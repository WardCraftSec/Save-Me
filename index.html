Save Me

Let's protect your device. This takes 5 minutes.

1. What is DNS?

When you type a website, your phone asks a "directory" (DNS) for the address. We're swapping in a directory that refuses to give out addresses for certain sites.

2. On your phone

Android 9+: Settings → Network → Private DNS → "Private DNS provider hostname" → type:

dns.adguard.com

iPhone: Settings → Wi-Fi → tap ⓘ → Configure DNS → Manual → add:

94.140.14.14

3. Test it

Try visiting a site you know is blocked. If it won't load — you're protected. That's a win.

Reading DNS logs

Each line is a question your device asked: "What's the address for X?"

Normal: short domain, well-known org (google.com, cloudfront.net)

Suspicious: very long random strings (DNS tunnelling), brand-new domains, domains that look like base64

MITRE ATT&CK (the cheat sheet)

When you see something suspicious, map it:

  • Long random subdomains → T1071.004 (DNS) / T1572 (Protocol Tunneling)
  • Known C2 IP → T1071 (Application Layer Protocol)
  • New domain resolving to data centre → T1568.002 (DNS Providers)
